# Verifold protocol specification (wire v2)

Status: UNAUDITED. This document specifies the demonstration verifier that is live on Stacks testnet. It makes no security claim. The standing gates hold: no mainnet and no value bearing use before external expert review and audit, as stated in README.md and both litepapers. Wire v2 is the normative format; wire v1 appears only in Appendix B as history.

## 1. Mathematical conventions

Every object in this protocol reduces to arithmetic in the Mersenne field M31 and its degree 4 extension QM31, evaluated over a subgroup of the unit circle. This section pins those objects and the conventions, orderings, and encodings an independent implementation must reproduce byte for byte.

```text
CM31 = M31[i]/(i^2 + 1) so i^2 = -1
QM31 = CM31[u]/(u^2 - (2+i)) so u^2 = R = 2 + i
An element {c0,c1,c2,c3} means (c0 + c1*i) + (c2 + c3*i)*u
```
